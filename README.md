# Recon Engine

A scope-aware reconnaissance engine developed during cybersecurity
assessment and authorized laboratory work.

## Features

- Scope validation
- HTTP discovery
- Protocol discovery
- Data parsing
- Data normalization
- Evidence handling
- Request logging
- Reporting
- Automated tests

## Purpose

The project demonstrates structured reconnaissance and evidence
handling within an authorized testing environment.

## Safety

This project is intended for authorized security testing only.
Do not scan systems without permission.
